📁 트윗 파일 추가

이번에 올리는 파일의 계정 아이디 (비우면 파일 이름을 써요. 이미 올린 트윗도 이 이름으로 바뀌어요)
📥 트위터 아카이브의 tweets.js 파일을 여기로 끌어다 놓으세요
폰에서는 아래 버튼으로 선택하세요 · 파일이 여러 개면 한꺼번에 선택해도 돼요

이미 저장된 트윗은 자동으로 건너뛰고 새 트윗만 클라우드에 추가해요. (영상 주소나 RT 원트 번호가 없던 옛 트윗은 그 정보만 보강해요.) 같은 파일을 여러 번 올려도 안전해요. 올린 트윗은 로그인한 모든 기기에서 보여요.

👤 계정 관리

계정 이름을 바꾸면 그 계정의 트윗 이름이 한꺼번에 바뀌어요. 프로필 사진은 작게 줄여서 저장돼서 모든 기기에서 보여요. (트윗 카드의 ⋯ 메뉴에서도 바꿀 수 있어요)

🔗 원문 링크 열기 방식 (이 기기에만 적용)

🎞️ 영상·움짤 파일 연결 (선택)

비공개 계정 영상처럼 인터넷 주소로 재생이 안 될 때 쓰세요. 아카이브 안의 data/tweets_media 폴더(또는 아카이브 폴더 전체)를 선택하면, 내가 올린 영상·움짤을 내 기기의 파일로 재생해요. 파일은 어디에도 업로드되지 않고, 이 창을 닫으면 연결이 풀려서 접속할 때마다 다시 선택해야 해요. (컴퓨터 브라우저 권장)

📦 사진 백업 (내 기기로 내려받기)

트윗을 지우기 전에 저장된 모든 트윗의 사진을 ZIP 파일로 내려받아요. (인용·답글 대상으로 이미 불러온 남의 사진도 포함) 사진은 원본 크기로 받고, 용량이 크면 여러 개 ZIP으로 나뉘어요. 컴퓨터에서 하시길 권장해요(폰은 메모리가 부족할 수 있어요). 여러 파일 내려받기 허용 창이 뜨면 "허용"을 눌러 주세요.
